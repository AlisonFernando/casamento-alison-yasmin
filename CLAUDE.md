# CLAUDE.md

## O que é

Convite de casamento (Alison & Yasmin) em React + TypeScript, publicado via GitHub Pages (`alisonfernando.github.io/casamento-alison-yasmin`). Usa framer-motion + GSAP pra motion, howler pra áudio, qrcode.react e react-router-dom.

## Stack

- React 19 + TypeScript + Vite 7
- Tailwind CSS 4
- framer-motion + GSAP pra animação
- howler (áudio), qrcode.react, react-router-dom
- Deploy: `npm run deploy` (gh-pages)

## Base de desenvolvimento

Práticas e pesquisa de referência ficam versionadas em `../claude-skill` (pasta irmã, mesmo nível de `F:\projetos`; repo: https://github.com/AlisonFernando/claude-skill). Mais aplicável aqui:

- `../claude-skill/docs/ui-ux.md` — gramática de motion (frequência/propósito/easing/velocidade) pra manter framer-motion + GSAP coerentes num convite que é, essencialmente, uma peça editorial curta.
- `../claude-skill/docs/web-design.md` — tipografia cinética e microinterações com propósito, se quiser elevar o nível visual do convite.
